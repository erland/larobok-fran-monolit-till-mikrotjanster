# Innehållscanon

- Språk: svenska; bokprofil: factbook.
- Fasta exempel: fiktivt ärendehanteringssystem, ett traditionellt system med frontend/backend/gemensam databas, senare dokumenttjänst som bryts ut.
- Två läsare: applikationsansvarig och drift-/infrastrukturansvarig.
- Mikrotjänster innebär inte automatiskt containrar, Kubernetes, DevOps eller decentraliserade säkerhetsmandat.
- Begreppen monolit, modulär monolit och distribuerad monolit får inte blandas ihop.
