# Källpolicy

- Kravnivå: hög för tekniska sakpåståenden; primärkällor/standarder och etablerad facklitteratur föredras.
- Synliga referenser och källförteckning: ja, när bokkapitlen färdigställs.
- Skilj mellan principer, rekommendationer, produktberoende uppgifter och organisationsval.
- Uppdatera versionsberoende och säkerhetsrelaterade uppgifter vid skrivning och publicering.
- Förklarande scenarier markeras som fiktiva. Hitta aldrig på källor eller citat.
- Underlag för faktakontroll förs i `docs/faktakontroll.md`.
