# Bokspecifikation – version 4, godkänd

- **Bokprofil:** faktabok (`factbook`), teknikneutral, förklarande och konkret.
- **Titel:** Från monolit till mikrotjänster.
- **Undertitel:** Hur arkitektur, ansvar, utveckling, drift och förvaltning förändras.
- **Språk:** svenska. **Författare:** ej fastställd.
- **Målgrupper:** dels erfarna från applikationssidan, dels erfarna från drift-/infrastruktursidan. Inga förkunskaper om mikrotjänster krävs.
- **Omfattning:** riktmärke 180–220 sidor; textens kvalitet styr verklig längd.
- **Tes:** Fördelad arkitektur kräver förändrad samordning av självständighet, beroenden och ansvar, men verksamheten behöver en sammanhållen IT-tjänst.
- **Stil:** lättillgänglig sakprosa, jämförande resonemang, realistiska motexempel, inga konfigurationsrecept.
- **Dramaturgi:** ett fiktivt ärendehanteringssystem utvecklas från monolit till delvis distribuerad tjänst. Följ samma dokumenthanteringsscenario genom boken.
- **Kapitelmodell:** traditionellt läge; förändring och orsak; möjligheter och begränsningar; applikationsperspektiv; driftperspektiv; ansvar; konkret scenario.
- **Källor:** originaldokumentation för principer och standarder; daterade källor för produkt-/verktygsuppgifter. Synlig källförteckning vid publicering.
- **Avgränsning:** inte en handbok i Kubernetes, programmering, DevOps, ITIL eller molnstrategi. Mikrotjänster är ett arkitekturval, inte ett självändamål.
- **Illustrationer:** interna arkitekturskisser/ansvarsbilder kräver separat uttryckligt godkännande; planerade endast som idéer. Omslagsbild ej beslutad.
