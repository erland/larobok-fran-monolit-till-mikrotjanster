# Kvalitetsgrind per kapitel

- [ ] Konkret problem som båda läsare kan relatera till
- [ ] Vad som ändras och varför, jämfört med monolit
- [ ] Tydligt värde för applikationsläsaren
- [ ] Tydligt värde för driftläsaren
- [ ] Ansvar: krav, beslut, utförande, drift och verifiering
- [ ] Alternativ och nackdelar – inga överdrifter om mikrotjänster
- [ ] Tydlig avgränsning mot övriga kapitel
- [ ] Faktapåståenden verifierade och källförda
- [ ] Läsarfärdig svenska utan redaktionella arbetsnoteringar
