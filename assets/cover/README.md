# Omslag

- Godkänd omslagsbild: `omslag.png` (992 × 1586 pixlar).
- Motiv: monolit övergår i ett nätverk av mikrotjänster.
- Titel, undertitel och författare är inbrända i bildfilen.
- `book.yaml` pekar på bilden och EPUB-exportskriptet använder den automatiskt.
- Befintliga provexporter från revision 56 är **inte** omgenererade och saknar därför det nya omslaget.
- Omslagsbildens läsbarhet och omslagsplacering i PDF ska slutkontrolleras vid nästa publiceringsrevision.
